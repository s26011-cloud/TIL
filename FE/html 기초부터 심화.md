#  HTML 기초부터 심화까지 (요약)

## 1. HTML 태그 이해하기

HTML 태그는 시작 태그와 종료 태그로 이루어지며, 웹 페이지의 구조와 콘텐츠를 정의합니다.

### 1.1 Void 요소 (빈 요소)

* 종료 태그가 필요 없는 **단일 태그 요소**입니다.
* 내부 콘텐츠를 포함하지 않으며, 대표적으로 줄바꿈 태그나 이미지 태그 등이 있습니다.
* **주의**: 최신 HTML 표준에서는 태그 끝에 닫는 슬래시(`/`)를 붙이지 않는 방식을 권장합니다.

### 1.2 Content와 Element

* **Content (콘텐츠)**: 시작 태그와 종료 태그 사이에 들어가는 실제 데이터(텍스트, 이미지 등).
* **Element (요소)**: 시작 태그, 콘텐츠, 종료 태그를 모두 포함하는 전체 구조.

### 1.3 Attribute (속성)

* HTML 요소에 추가 정보를 제공하며 **시작 태그 안**에 위치합니다.
* 속성은 이름과 값의 쌍으로 구성되며, 요소의 동작이나 스타일을 정의하는 데 중요한 역할을 합니다.

## 2. HTML 요소 분류 (인라인 vs 블록)

| 구분 | **인라인 요소 (In-line Element)** | **블록 요소 (Block Element)** |
| --- | --- | --- |
| **줄바꿈** | 줄바꿈 없이 같은 라인에 연속 배치 | 항상 새로운 줄에서 시작 |
| **너비** | 콘텐츠 크기만큼 차지 | 부모 요소의 전체 너비(100%) 차지 |
| **특징** | 텍스트나 일부 요소만 포함 | 다른 블록 요소나 인라인 요소를 포함 가능 |

---

## 3. 콘텐츠 모델 (Content Models)

HTML 요소들은 역할과 특징에 따라 다음과 같은 모델로 분류됩니다.

* **Metadata Content**: 페이지 정보 및 메타데이터를 포함하는 요소 (문서 제목, 메타 태그 등)
* **Flow Content**: 거의 모든 HTML 요소가 포함되는 기본 그룹
* **Sectioning Content**: 페이지의 논리적 구역을 나누는 요소
* **Heading Content**: 섹션의 제목을 나타내는 요소
* **Phrasing Content**: 텍스트 및 텍스트 내 구문 역할 요소
* **Embedded Content**: 외부 리소스를 삽입하는 요소 (이미지, 동영상 등)
* **Interactive Content**: 사용자와의 상호작용을 담당하는 요소 (버튼, 링크 등)

---

## 4. HTML 문서의 기본 골격

HTML 문서는 논리적이고 표준화된 구조를 가져야 검색 엔진 최적화(SEO)와 유지보수에 유리합니다.

* **DOCTYPE 선언**: 해당 문서가 HTML5 표준을 따름을 명시
* **html 요소**: HTML 문서의 루트(Root) 요소로 모든 내용을 포함
* **head 요소**: 문서 제목, 인코딩, 메타데이터 등 화면에 보이지 않는 정보 포함
* **body 요소**: 실제로 브라우저 화면에 표시되는 콘텐츠(텍스트, 이미지 등) 포함

## 5. 시맨틱(Semantic) HTML 작성법

의미에 맞는 **시맨틱 태그**를 사용하면 검색 엔진과 스크린 리더가 페이지 구조를 정확히 이해할 수 있습니다.

* **제목 태그 (`<h1>` ~ `<h6>`)**: 페이지 및 섹션의 계층 구조 표현
* **머리말 (`<header>`)**: 상단 영역 (로고, 검색바 등)
* **내비게이션 (`<nav>`)**: 메뉴 및 링크 그룹
* **주요 콘텐츠 (`<main>`)**: 페이지의 핵심 독자적 콘텐츠
* **독립 콘텐츠 (`<article>`)**: 블로그 포스트, 기사 등 독립적으로 재사용 가능한 콘텐츠
* **섹션 (`<section>`)**: 논리적으로 연관된 콘텐츠 그룹
* **사이드바 (`<aside>`)**: 본문과 별도의 관련 콘텐츠 (광고, 관련 링크 등)
* **바닥글 (`<footer>`)**: 하단 영역 (저작권, 연락처 정보 등)

## 6. HTML 기반 SEO (검색엔진 최적화) 가이드

1. **Title 태그**: 검색 결과 상단에 표시되는 제목으로, 내용을 명확히 나타내도록 작성
2. **Meta Description**: 검색 결과에 나타나는 요약문 (150자 이내, 주요 키워드 포함)
3. **Header 태그 활용**: 계층 구조에 맞춰 적절한 헤더 태그에 키워드 배치
4. **Alt 속성**: 이미지에 대한 설명 텍스트를 제공하여 검색 엔진의 색인 지원
5. **URL 구조 & 내부 링크**: 이해하기 쉬운 URL을 사용하고 관련 페이지 간 내부 링크 배치
