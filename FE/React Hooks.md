# useState
- 함수형 컴포넌트 내부에서 가변적인 상태(state)를 생성하고 관리할 수 있게 해주는 가장 기본적인 Hook이다.

- 상태가 업데이트되면 해당 컴포넌트와 하위 컴포넌트는 리렌더링된다.

# useEffect
- 컴포넌트의 렌더링이 완료된 후(화면에 그려진 뒤) API 호출, DOM 직접 수정, 이벤트 리스너 등록 등 사이드 이펙트(Side Effect)를 수행하도록 설정하는 Hook이다.

- 의존성 배열(deps)을 통해 실행 시점(마운트, 특정 값 변경, 언마운트 등)을 제어할 수 있다.

# useContext
- 부모-자식 간에 일일이 props를 넘겨주는 현상(Props Drilling)을 방지하기 위해 사용한다.

- 애플리케이션 전체 혹은 특정 컴포넌트 트리 하위 영역에 데이터를 쉽게 공유(전달)할 수 있게 해준다.

# useReducer
- useState보다 복잡한 상태 변경 로직이 필요할 때 사용하는 Hook이다.

- 상태 업데이트 로직을 컴포넌트 외부로 분리하여 관리할 수 있다.

# 리듀서(reducer)
- 현재 상태(state)와 업데이트에 필요한 정보가 담긴 액션(action) 객체를 전달받아 새로운 상태를 반환하는 순수 함수이다.

# useMemo
- 함수형 컴포넌트 내부에서 발생하는 복잡한 연산 결과를 메모이제이션(캐싱)하여 성능을 최적화하는 Hook이다.

- 의존성 배열의 값이 변경되지 않았다면 이전에 계산해둔 결과값을 재사용한다.

# useCallback
- 컴포넌트가 리렌더링될 때 이전에 생성된 함수의 참조(Reference/메모리 주소)를 재사용(캐싱)하도록 해주는 Hook이다.

- 자바스크립트 특성상 리렌더링 시 함수 객체 자체는 매번 새로 만들어지지만, useCallback을 사용하면 동일한 참조값을 유지해주어 React.memo 등으로 감싸진 자식 컴포넌트의 불필요한 리렌더링을 방지한다.

# useRef
- 렌더링에 영향을 주지 않는 가변 값을 저장하거나, 실제 HTML 태그(DOM)에 접근할 때 사용하는 Hook이다.

# ref란
- 렌더링을 일으키지 않는 변수 또는 DOM 요소에 직접 접근할 수 있는 통로이다.

- 화면 표시(UI) 변경과 무관한 내부 데이터 저장이나, Focus, 스크롤 위치 제어 등 실제 HTML 태그(DOM)를 직접 조작할 때 사용한다.

# DOM이란
- 브라우저가 HTML 문서를 자바스크립트가 조작할 수 있도록 메모리에 생성한 `객체 형태의 트리(Tree)` 구조이다.
