# useState
- 가장 기본적인 Hook으로써 함수형 컴포넌트에서도 가변적인 상태를 지니고 있을 수 있게 한다.

- 함수 컴포넌트 안에서 상태(state)를 만들고 관리할 수 있게 해주는 Hook이다.

# useEffect
- 리액트 컴포넌트가 렌더링 될 때마다 특정 작업을 수행하도록 설정 할 수 있는 Hook이다.

# useContext
- 이 Hook을 사용하면 함수형 컴포넌트에서 Context를 보다 더 쉽게 사용 할 수 있습니다.

 - React에서 부모와 자식 간에 일일이 ``props``를 넘기지 않고 <b>전역 데이터</b>를 쉽게 공유할 때 쓰는 훅이다.


# useReducer
- useState 보다 컴포넌트에서 더 다양한 상황에 따라 다양한 상태를 다른 값으로 업데이트 해주고 싶을 때 사용하는 Hook이다.

## 리듀어(reducer)
- 현재 상태와, 업데이트를 위해 필요한 정보를 담은 액션(action) 값을 전달 받아 새로운 상태를 반환하는 함수이다.

# useMemo
- 함수형 컴포넌트 내부에서 발생하는 연산을 최적화 할 수 있다.

# useCallback
- useMemo와 상당히 비슷한 함수이다.

- 주로 렌더링 성능을 최적화 해야하는 상황에 사용을 한다.

- 이벤트 핸들러 함수를 필요할 때만 생성할 수 있다.

# useRef
- 함수형 컴포넌트에서 ref를 쉽게 사용할 수 있게 해준다

## ref란
- 렌더링을 일으키지 않는 변수 또는 DOM 요소에 접근할 수 있는 통로이다

- React에서 화면을 바꾸려면 ``useState``를 사용하지만 화면 표시와 상관없는 데이터나 실제 HTML 태그(DOM)를 건드릴 때 ref를 사용한다.

### DOM이란
- 브라우저가 HTML 문서를 자바스크립트가 조작할 수 있도록 메모리에 생성한 ``객체 형태의 트리(Tree)`` 구조이다.
