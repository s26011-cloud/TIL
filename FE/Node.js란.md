# Node.js란
- 원래 웹 브라우저 안에서만 작동하던 자바스크립트(JavaScript)를 컴퓨터나 서버에서도 실행할 수 있게 해주는 <b>자바스크립트 실행 환경(런타임)</b>

## Node.js의 핵심 특징과 장점
- 언어의 통일: 웹 페이지를 꾸밀 때 자바스크립트 하나만으로 프론트(화면)와 백엔드(서버)를 모두 개발 할 수 있다.

- 빠른 속도와 확장성: 비동기 이벤트 기반 모델을 사용하여, 요청이 들어올 때까지 기다리지 않고 여러 작업을 처리할 수 있다.
 
 - 거대한 생태계: 세계 개발자들이 만들어 둔 오픈소스와 라이브러리를 무료로 가져다 쓸 수 있다.
